# High performance computing course
The project title - Interface debonding driven by CO2 injection in a cased and cemented wellbore.

Crack propagation modeling was performed using the finite-difference method with parallelization via MPI, OpenMP, and CUDA.
The results are available at the link https://docs.google.com/presentation/d/1Fj7MMTSSY0aRF6oSjS_y7RsphHCndy98eUD3fpTtRVU/edit?usp=sharing
