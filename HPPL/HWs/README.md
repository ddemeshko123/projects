# Home work

1. Julia set - generating and visualizing Julia sets using iterative methods.
2. Life - implementation of a game of life.
3. Bifurcation map - parallelization of the computation of a bifurcation map using MPI and analyses of its speedup.
4. Integral parallel - parallelization of the numerical integration of the function.
5. Julia numba - comparison of the performance of a pure Python implementation of a Julia set fractal generator with an optimized version using Numba's JIT compilation.
6. Shift - implementation of parallel image shifting animation using MPI.
7. Spectrogram - parallel computation of a spectrogram using MPI.
