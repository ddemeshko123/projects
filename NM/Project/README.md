# Project
The project title - Interface debonding driven by CO2 injection in a cased and cemented wellbore.

Crack propagation modeling was performed using finite-difference explicit and implicit schemes.
The convergence and stability were analysed.

Results are available at the link https://docs.google.com/presentation/d/1U5oBKwRvBzcvTYVmxoqOIlK9GXt2MfpQyb9gvbvLMgY/edit?usp=sharing
